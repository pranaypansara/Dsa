- Method overloading
- `toString()` overrides

## Running the code

Compile and run a file with the JDK:

```bash
javac OOP/Main.java
java -cp OOP Main
```

For files inside package folders, compile from the repository root and use the package name:

```bash
javac OOP/Constructor/Constructor.java
java -cp OOP Constructor.Constructor
```
